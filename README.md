# 光影相框 · 使用说明

一个单文件的批量相框工具。把照片拖进去，选个版式，一次导出全部。

自动读取相机、镜头、光圈、快门、ISO、焦距、日期，排进画面；也支持全部手写。
不用装任何东西，不用联网，双击 HTML 就能跑。

```
光影相框.html          当前版本（8 种版式）
光影相框_v1_备份.html   早期快照（7 种版式，无「光影」）
```

---

## 一、快速开始

1. 双击 `光影相框.html`，用浏览器打开（Chrome / Edge / Safari 均可）
2. 把照片拖进窗口，或点右上角「＋ 添加照片」
3. 左侧选版式、调参数，右侧实时预览
4. 点「导出 N 张」，得到一个 zip

拖进去多少张就处理多少张，参数是全局的，一次套用。

- **左侧**：所有参数，改完立刻重绘，无需点确认

- **点击预览图**：打开大图查看（Esc 或点空白处关闭）

## 三、八种版式

| 版式 | 观感 | 适合 |
|---|---|---|
| **胶片** | 米色卡纸、左对齐信息、带颗粒感 | 日常记录、旅行、人文 |
| **拍立得** | 暖白、居中、底部大留白 | 单张精选、礼物、手账 |
| **留白** | 纯白、极简、居中、宽边距 | 作品集、展览、电商 |
| **银幕** | 近黑底、左侧竖条、宽画幅感 | 电影感、夜景、氛围图 |
| **杂志** | 灰米色、衬线字、顶部细线 | 编辑风、人像、专题 |
| **悬浮条** | 照片满幅，信息压在底部 | 手机壁纸、社交平台 |
| **柔焦** | 主体清晰、边缘融入虚化背景 | 情绪片、静物、浅景深 |
| **光影** | 深色底、底部居中水印（圆点+品牌） | 品牌署名、作品打标 |

### 两个「特殊」版式

**柔焦** 和 **光影** 的文字逻辑与其余六个不同，值得单独说明：

- 其余六个版式用「**信息模板**」——可以写多行，用 `|` 分隔
- 柔焦 / 光影 用「**底部文字**」——固定两行 + 署名，样式与排版统一

这样设计是因为这两个版式的文字是「水印」性质，需要紧凑、居中、有品牌感，而不是信息罗列。

## 四、参数详解

### 4.1 版式参数（所有版式通用）

| 参数 | 范围 | 说明 |
|---|---|---|
| **边距** | 1% – 14% | 相对画面短边的百分比。越大越像卡纸装裱 |
| **字号** | 1% – 4% | 所有文字的整体缩放。光影/柔焦下是相对基准值的倍率 |
| **圆角** | 0% – 3% | 照片四角的圆角半径 |
| **投影** | 开 / 关 | 照片下方的投影 |
| **颗粒** | 关 / 全图 / 仅主体 / 主体以外 | 胶片颗粒，见 4.5 |

切换版式时会自动套用该版式的默认配色、边距和字号，但**圆角、模糊强度、底图亮度**会重置为该版式的默认值——避免上一个版式的参数串过来。

### 4.2 边缘模糊（仅柔焦版式）

| 参数 | 范围 | 说明 |
|---|---|---|
| **模糊强度** | 1% – 18% | 背景虚化程度 |
| **背景放大** | 100% – 180% | 底图放大倍数，防止虚化后四周露边 |
| **背景亮度** | 50% – 115% | 底图明暗，压暗可突出主体 |
| **主体大小** | 55% – 96% | 清晰主体占画面短边的比例 |
| **边缘羽化** | 0% – 25% | 主体边缘的柔和过渡。**调到 0 就是硬边卡片** |
| **边缘阴影** | 0% – 100% | 主体下方的投影强度。调到 0 则完全浮在背景上 |

柔焦的层次是：虚化底 → 清晰主体 → 边缘羽化融入 → 阴影分离 → 底部文字。

### 4.3 底部文字（仅柔焦 / 光影）

| 参数 | 说明 |
|---|---|
| **第一行** | 默认 `{camera}`，渲染为「● 品牌机型」 |
| **第二行** | 默认 `{params}`，即拍摄参数 |
| **底图模糊 / 亮度** | 仅光影版式显示（柔焦用自己那组） |

规则：

- 两行都留空 → 只显示署名
- 第一行留空、第二行有内容 → 第二行自动提上来占第一行位置
- 两行都留空且没有署名 → 不占任何空间
- 没有 EXIF 的照片 → 两行自动消失，不留空行

### 4.4 文字

| 参数 | 说明 |
|---|---|
| **标题** | 全局标题，可被单张图的标题覆盖 |
| **信息模板** | 多行信息，用 `\|` 分行。空值自动省略 |
| **署名** | 光影/柔焦下是底部第三行；其他版式是信息区末尾一行 |

### 4.5 颗粒

四档，解决「颗粒该加在哪儿」的问题：

| 模式 | 效果 |
|---|---|
| **关闭** | 无颗粒 |
| **全图** | 整个画面（照片 + 边框）都带颗粒 |
| **仅主体** | 只有照片有颗粒，边框和背景保持干净 |
| **主体以外** | 只有边框和背景有颗粒，照片保持干净 |

柔焦版式下，颗粒会跟着**羽化边缘**一起渐变，不会在主体边界切出一条直线。

想模拟胶片：选「全图」。
想让照片有质感但边框干净：选「仅主体」。
想做旧纸张 / 底片边缘效果：选「主体以外」。

### 4.6 配色

三个色：**底色**（卡纸/背景）、**文字**、**点缀色**（圆点、竖条、分隔线）。

每个都提供预设色板，也可以直接调色。

### 4.7 画幅与输出

| 参数 | 说明 |
|---|---|
| **比例** | 跟随原图 / 1:1 / 4:5 / 3:2 / 16:9 / 3:4 |
| **输出长边** | 1080 / 1600 / 2000 / 3000 / 4000 px / **原始尺寸** |
| **格式** | JPG（体积小）/ PNG（无损） |
| **JPG 画质** | 标准 0.90 / 高 0.95 / 最高 0.99 |

**关于画质**：想完全不损失，选「原始尺寸」+「PNG」。原始尺寸按照片本身的像素导出，不做任何缩放。

## 五、Token 完整参考

写在「信息模板」「底部文字」里都有效，导出时替换成真实值。

| Token | 输出示例 | 说明 |
|---|---|---|
| `{camera}` | `NIKON Z5_2` | 机身，已自动精简 |
| `{lens}` | `NIKKOR Z 24-70mm f/2.8 S` | 镜头 |
| `{params}` | `45mm f/2.8 1/60s ISO 800` | 拍摄参数一行式 |
| `{focal}` | `45mm` | 焦距 |
| `{aperture}` | `f/2.8` | 光圈 |
| `{shutter}` | `1/60s` | 快门 |
| `{iso}` | `ISO 800` | 感光度 |
| `{date}` | `2026.10.20` | 拍摄日期 |
| `{size}` | `4000×2667` | 像素尺寸 |
| `{filename}` | `IMG_0001.jpg` | 原文件名 |

**机身名的自动精简**：EXIF 里常写成 `NIKON CORPORATION` + `NIKON Z5_2`，直接拼会又长又重复。工具会自动去掉公司后缀（`CORPORATION`、`INC`、`CO., LTD.`、`IMAGING` 等），并在机型已含品牌时不再重复拼接。

```
NIKON CORPORATION + NIKON Z5_2  →  NIKON Z5_2
Canon + Canon EOS R5            →  Canon EOS R5
SONY + ILCE-7RM5                →  SONY ILCE-7RM5
RICOH IMAGING COMPANY, LTD. + PENTAX K-3 III  →  RICOH PENTAX K-3 III
```

机型里的下划线原样保留（`Z5_2` 不会变成 `Z52`）。

## 六、导出

点「导出 N 张」→ 浏览器下载一个 zip。

- **命名**：`原名_framed.jpg`，重名自动加 `_2`、`_3`
- **打包**：`光影相框_20261026.zip`
- **只导出勾选的**：卡片左上角可以取消勾选

体积参考（一张 4000×2667 的图）：

| 设置 | 输出尺寸 | 体积 |

| 0.90 @ 2000px | 2000×1334 | 134 KB |
| 0.95 @ 2000px | 2000×1334 | 187 KB |
| 0.99 @ 2000px | 2000×1334 | 311 KB |
| 0.95 @ 原始尺寸 | 4000×2667 | 427 KB |
| PNG @ 原始尺寸 | 4000×2667 | 1771 KB |

## 七、几个配方

**给作品集做统一打标**
> 光影版式 → 第一行填 `HASSELBLAD`（或留默认 `{camera}`）→ 第二行留 `{params}` → 署名填 `© 你的名字` → 边距 2.6% → 原始尺寸 + PNG

**情绪人像 / 浅景深感**
> 柔焦版式 → 模糊强度 12% → 主体大小 78% → 边缘羽化 8% → 边缘阴影 70% → 颗粒「仅主体」

**手机壁纸**
> 悬浮条 → 16:9 → 1080px → 字号 1.6%（小一点更耐看）

**复古胶片**
> 胶片版式 → 颗粒「全图」→ 底色换成 `#E9E3D8` → 点缀色换 `#8C8378`

**极简白墙**
> 留白版式 → 边距 9% → 字号 1.8% → 圆角 0% → 关闭投影

## 八、常见问题

**Q：为什么有些照片显示「无 EXIF 信息」？**

EXIF 解析只针对 **JPEG**。PNG、WebP 里没有相机元数据（或者格式不同），所以读不到。画面照常渲染，只是相机信息那几行会空着。

**Q：导出的图里有 EXIF 吗？**

没有。相机信息是**画进画面**的，文件本身的元数据是空的。这样在任何平台都不会因为元数据被剥离而丢失信息。

**Q：为什么拖参数时画面不抖了？**

预览按屏幕实际像素固定渲染尺寸，画布盒子用 `aspect-ratio` 锁死，所以改参数不会触发页面重排。之前会抖是因为预览先出小图、停手再换大图，画布尺寸一变整页就跳。

**Q：支持 HEIC 吗？**

不支持。浏览器原生解码不了 HEIC。iPhone 可以在「设置 → 相机 → 格式」里改成「兼容性最佳」，或导出时选 JPEG。

**Q：参数会保存吗？**

点「我的预设 → 保存当前样式」，存在本机浏览器里，下次打开自动恢复。换电脑或清缓存就没了。

**Q：能批量处理整个文件夹吗？**

现在只能手动拖。如果你需要命令行批处理版本，可以说一声。

**Q：一次能处理多少张？**

没有硬限制，但几十张以上建议分批，避免浏览器内存吃紧。2000px 单张渲染约 1–4ms，主要开销在解码大图。

## 九、实现说明

给好奇的人。

**零依赖**：没有 CDN、没有 npm 包、没有字体文件，断网可用。所有逻辑在一个 HTML 里，分三段脚本：

```
CORE      纯逻辑：EXIF 解析、CRC32、ZIP 打包、token 展开、机身名清洗
渲染引擎    Canvas 2D：8 个版式的绘制、羽化、颗粒、文字排版
应用层     DOM：状态管理、事件绑定、导出流程
```

**EXIF 解析**是手写的：JPEG APP1 段 → TIFF 头（大小端兼容）→ IFD 遍历 → Exif 子 IFD，按 tag 取机身、镜头、光圈、快门、ISO、焦距、日期。

**ZIP 打包**也是手写的：CRC32 查表 + store-only（不压缩）结构。照片本身已是压缩格式，再压意义不大，直接存能省 CPU。

**边缘羽化**用 `destination-in` 配合四边线性渐变，缓入曲线 `0 → 0.22 → 0.72 → 1`，避免两段式渐变的生硬感。

**渐进失焦**：清晰层下面垫一层同亮度、同位置的虚化层，边缘不是「淡出成背景」而是「逐渐失去焦点」，观感更接近真实镜头。

**颗粒**用 128×128 的噪点贴图平铺，按画面短边缩放（2000px 输出约 2.6px 一颗），`overlay` 混合模式叠加。主体/边缘两种模式通过羽化蒙版的 `destination-in` / `destination-out` 实现，边界会跟着羽化一起渐变。

## 十、已知限制

- **只读 JPEG 的 EXIF**，PNG/WebP 无相机信息
- **不支持 HEIC**（浏览器解码限制）
- **导出无元数据**（信息已烧录进画面）
- **原始尺寸上限 12000px 长边**，超出会按 12000 处理，防止 canvas 内存溢出
- **ZIP 不压缩**，体积约等于所有成品图之和
- 参数预设存在 localStorage，换浏览器/清缓存会丢
